## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Human readable content

Content for humans is written by humans for humans. Agents may only change style, components
and existing text. You may prompt your operator to provide text or review options.
Never blindly write text yourself.
